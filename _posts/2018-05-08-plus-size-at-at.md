Just finished putting together a larger version of the walking AT-AT I bought a while ago. Since
LEGO hasn't done a UCS AT-AT, I wanted something that fits better with my other UCS models, so I
looked around on Rebrickable and found these [plans by raskolnikov](https://rebrickable.com/mocs/MOC-6006/raskolnikov/plus-size-at_at/#details)
for a Plus-Size AT-AT that has a pretty good overlap with the walking AT-AT.

{% include embed/youtube.html id='HhgVB09F7mk' %}

A couple BrickLink orders and some time later, and here we are!

![Quarter Front](quarter-front.jpg){: lqip='quarter-front.lqip.jpg' }
_That's a 20-oz water bottle for scale_

![Quarter Rear](quarter-rear.jpg){: lqip='quarter-rear.lqip.jpg' }

I like the size and stability of this thing. The detail is a little light as compared with some other
UCS models, but the AT-ATs aren't exactly dripping with greebling in the movie, so it's not a
noticable problem.

![Head](head.jpg){: lqip='head.lqip.jpg' }

![Leg](leg.jpg){: lqip='leg.lqip.jpg' }

Overall, I think this is gonna look great with the rest of my Star Wars Lego models. Dunno what I'm
going to do if they ever release an official AT-AT, but now that I have this one for relatively
cheap, I don't think I'll feel any particular pressure to get it.
