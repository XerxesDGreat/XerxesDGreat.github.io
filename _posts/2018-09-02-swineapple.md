I was tooling around online and I read about a thing called a "Swineapple", which is pork tenderloin
(or other cuts) put into a skinned and cored pineapple which is wrapped in bacon, then the whole
thing grilled; I just had to give it a shot, so I roped Cora into helping me

![Ingredients](ingredients.jpg){: lqip='ingredients.lqip.jpg' }

First, we need a whole pineapple, some pork, and a pack of bacon.

![Coring](coring-pineapple.jpg){: lqip='coring-pineapple.lqip.jpg' }

Cut the top off the pineapple, peel the skin off, and then core the inside to leave a cavity for
the pork.

![Pork laid out](pork-laid-out.jpg){: lqip='pork-laid-out.lqip.jpg' }

Slice the pork into long strips, then stuff them into the pineapple.

![Bacon weave](bacon-weave.jpg){: lqip='bacon-weave.lqip.jpg' }

Now create the bacon weave by ... uh ... weaving the bacon together into a mat.

![Prepped](prepped.jpg){: lqip='prepped.lqip.jpg' }

Wrap the pineapple in the bacon weave, pinning it in place with some toothpicks

![On display](on-display.jpg){: lqip='on-display.lqip.jpg' }

While this part isn't _necessary_, it certainly helps the display. Tack the pineapple top
back onto the rest using toothpicks. Now grill over medium heat for 45 min-an hour until
the pork is done (you can use a meat thermometer, but make sure you get it into the pork, not
just the pineapple).

![Grilling](grilling.jpg){: lqip='grilling.lqip.jpg' }

When it's finished cooking, it's gonna look nice and brown; slice it into disks like the post preview
photo and you're done!

Hope you enjoy your own, if you make one. Thanks for reading!
